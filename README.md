# 📧 Email Spam Detection using Machine Learning

## 📌 Overview
This project focuses on building an automated system to classify email messages as **spam** or **non-spam (ham)** using machine learning techniques. It applies natural language processing (NLP) methods to convert textual data into numerical features and evaluates different classification models to determine the most effective approach.

---

## 🎯 Objective
- To develop a reliable spam detection model using machine learning  
- To preprocess and transform textual email data for analysis  
- To compare multiple classification algorithms and select the best-performing model  

---

## 🧠 Methodology

### 1. Data Preprocessing
- Text cleaning and normalization  
- Tokenization  
- Removal of stop words  
- Handling irrelevant/noisy data  

---

### 2. Feature Extraction
- Bag-of-Words (BoW)  
- TF-IDF (Term Frequency–Inverse Document Frequency)  

---

### 3. Model Training & Evaluation
The following models were trained and compared:
- Naïve Bayes  
- Support Vector Machine (SVM)  
- Other baseline classifiers  

Evaluation metrics used:
- Accuracy  
- Precision  
- Recall  
- F1-score  

---

### 4. Model Selection
- Naïve Bayes demonstrated the best performance for this dataset  
- Selected as the final model for spam classification  

---

## 📊 Results
- Achieved high accuracy in distinguishing spam and non-spam emails  
- Confusion matrix used to analyze classification performance  
- Demonstrated effectiveness of NLP + ML for text classification problems
